# 파이프라인 통일 결정 사항

보험·바이오·IT 파일럿 노트북(`notebook/`)의 파이프라인을 통일하면서 확정한 결정을 기록한다.
산업별 파이프라인 비교 정리는 노션 "각 산업군 파이프라인 요약 정리" 페이지 참고.

## 사전 합의 (10월 회의)

- 서프라이즈 강도는 회사 기준 (not 시장)
- 실적 발표 여부 + 서프라이즈(커짐 / 작아짐 / 예상)로 비교
- 서프라이즈는 continuous로 사용
- 대조군 선택 규칙: 처치 반응일 ±10거래일 안에 자기 발표가 없는 회사

## 서프라이즈 원값: 주가 기준(SUE)으로 통일 (2026-11-08)

- SUE = (실제 EPS − 컨센서스) ÷ 반응일 2거래일 전(t0−2) 종가 × 100 (%)
- 이유: 결과변수가 주가 반응(수익률)이라 단위가 맞고, 컨센서스로 나누면 컨센서스가 0 근처일 때 값이 폭발한다.
- 분할 문제는 분할 조정된 EPS·주가로 해결한다. IT 파일럿이 컨센서스 기준(%)을 택한 이유가 이 문제였다.
- 컨센서스 기준(%)은 강건성 점검용으로만 남긴다.
- 적용: 보험은 현행 유지, 바이오는 ×100 단위만 맞춤, IT는 서프라이즈% → SUE로 변경
- 미확정: 분모 종가를 분할만 조정할지(보험 방식), 배당까지 조정할지(바이오 방식)

## 회사 기준 표준화: 직전 8분기 평균·SD (2026-11-08)

- 점수 = (이번 SUE − 직전 8분기 SUE 평균) ÷ 직전 8분기 SUE 표준편차
- 그 발표 이전 분기만 쓴다. 전체기간으로 계산하면 당시 투자자가 몰랐던 미래 분기가 섞인다. 보험 파일럿에서 과거 분기만 쓰자 효과가 2.33 → 1.19로 줄었다.
- 과거 기록이 4분기 미만이면 점수를 계산하지 않는다. 그래서 분석 시작 시점보다 최소 1년(권장 2년) 앞선 실적 기록을 받아야 한다.
- 평균을 빼므로 0 = "그 회사 평소 수준"이다. 바이오 파일럿처럼 SD로만 나누면 0 = 컨센서스 부합이 되어, 평소만큼 넘긴 발표도 큰 양의 서프라이즈로 잡힌다.
- 적용: 보험은 전체기간 → 직전 8분기, 바이오는 평균 차감 추가 + 직전 8분기, IT는 방식 유지
- SD 하한·극단값 처리는 아래 "SD 하한 · 극단값 처리" 참고

## 커짐 / 작아짐 / 예상: ±0.5SD (2026-11-08)

- 회사 기준 점수 > +0.5 커짐 / < −0.5 작아짐 / 그 사이 예상
- 강건성으로 ±1SD 기준도 추정한다.
- 적용: 보험은 현행 유지, 바이오·IT는 3그룹 분류와 비교 분석을 추가해야 한다.

## 결과변수 · 벤치마크 · 기준시점 (2026-11-08)

- 결과변수는 분석의 질문에 맞춰 다르게 쓴다.
  - 발표 여부: |AR| + 비정상 log 거래량(기준구간 t−60~t−21). 좋은 실적과 나쁜 실적이 상쇄되므로 방향 있는 AR·CAR은 쓰지 않는다.
  - 서프라이즈(3그룹·연속처치): CAR. 반응의 지속·되돌림까지 보기 위해서다.
  - 산업 간 비교용 대표 숫자: 발표 여부는 k=0의 |AR|·거래량, 서프라이즈는 CAR[0,+1]. CAR[0,+1]은 AMC 반응일이 하루 어긋나도 안정적이다.
- 벤치마크: AR = 회사 수익률 − SPY 수익률. 업종 ETF(KIE·XLV·XLK)는 강건성으로만 쓴다.
  - 업종 ETF는 산업마다 달라 공통 잣대가 아니다. 또 표본 회사 자신이 ETF에 크게 포함돼 있어(XLK의 애플·MS 등) 효과가 작게 잡힌다.
- 기준시점: CAR은 k=−1, |AR|·거래량은 k=−10~−6 구간 평균. 하루짜리 기준은 잡음이 크고, 거래량은 발표 며칠 전부터 오른다.
- 적용: 보험은 현행 유지 / IT는 서프라이즈 분석 AR → CAR, ^GSPC → SPY, |AR| 기준구간 −10~−4 → −10~−6 / 바이오는 cr → SPY 기준 CAR, 발표 여부에 |AR| 추가

## 분석별 모형 구조 (2026-11-08)

- 발표 여부(|AR|·거래량): 스택 DiD, 대조군 = 같은 시기 미발표 회사. 세 노트북 공통 구조를 유지한다.
- 연속처치: 발표 이벤트만 쓰는 모형(A). 미발표 대조군 없이 점수가 낮은 발표가 비교 기준이 된다.
- 3그룹 비교: A 구조에 점수 대신 커짐·작아짐 더미를 넣고 '예상'을 기준으로 둔다. 연속처치와 표본·고정효과가 같아서 두 결과를 나란히 비교할 수 있다.
- 고정효과: 이벤트 FE + 하위그룹×k + 분기×k. 세 개를 곱하면 칸당 이벤트가 1~3개뿐이라 더하는 방식으로 넣는다. 표준오차는 회사 클러스터.
  - 분기×k는 같은 어닝시즌 발표끼리 비교해 시즌 공통 분위기를 제거한다. 하위그룹×k는 업종별 반응 패턴을 제거한다.
  - 같은 분기라도 발표 날짜가 달라 특정 하루의 업종 뉴스는 완전히 걸러지지 않는다. 보험은 재해 분기에 EPS 하락과 업종 하락이 겹쳐 서프라이즈 효과가 부풀 수 있다.
- 교차확인: ① DiD 안에서 처치×점수(B, 바이오 방식, 같은 날짜 대조군으로 업종 뉴스까지 제거) ② ±10일 안 '예상' 이벤트와 매칭(보험 질문 A 방식) ③ 업종 ETF 기준 CAR
- A를 메인으로 고른 근거: 바이오에서 같은 119개 이벤트로 비교하면 A와 B의 점수 효과가 1.07로 같았다. 차이는 방법이 아니라 표본 크기에서 생기고, A는 대조군이 필요 없어 표본 손실이 없다.
- 적용: 보험은 분기×k 추가, 3그룹 비교를 매칭 → 더미 방식(매칭은 강건성) / IT는 하위그룹×k 추가, 3그룹 더미 추가 / 바이오는 메인을 B → A(기존 Method B), 3그룹 더미 추가
- 확인 필요: 두 고정효과를 함께 넣었을 때 추정이 안정적인지 실제 데이터로 점검

## 대조군 세부 규칙 (2026-11-08)

- 기본 규칙(합의): 처치 반응일 ±10거래일 안에 자기 발표가 없는 회사
- 대조군 풀: 같은 산업 전체. 다른 하위그룹만 쓰는 버전은 강건성.
  - 하위그룹 제한은 경쟁사 스필오버(처치 회사 발표가 경쟁사 주가도 움직여 효과가 작게 잡힘)를 막으려는 것이다.
  - 그러나 스필오버 증거가 약했고(바이오 검정 0.159, p=0.18 / IT 5.42 vs 5.41), 제한하면 표본 손실이 컸다(바이오 186 → 119/272).
- 최소 대조군 수: 1개. 최소 2개 버전은 강건성. 이벤트를 수백 개 쌓으면 개별 대조군 잡음은 상쇄되고, 보험은 대조군 중앙값이 1개라 2개를 요구하면 표본이 크게 준다.
- 자기 발표 판정: 분석 기간 앞뒤 발표를 포함한 전체 발표 기록으로 한다. 보험 파일럿은 분석 대상 이벤트만으로 판정해서 2021년 2월의 2020Q4 발표가 빠졌을 가능성이 있다(코드 기준 추정, 확인 필요).
- 영향 범위: 발표 여부 분석(|AR|·거래량)과 교차확인 B에만 적용. 메인 서프라이즈 분석(A)은 대조군을 쓰지 않는다.
- 적용: 보험은 자기 발표 판정에 분석 기간 이전 발표 추가 / 바이오는 풀을 산업 전체로, 최소 2개 → 1개 / IT는 현행 유지

## SD 하한 · 극단값 처리 (2026-11-08)

- SD 하한: 그 산업 모든 이벤트의 직전 8분기 SD 중 하위 10% 값. 점수 = (SUE − 직전 8분기 평균) ÷ max(직전 8분기 SD, 하한)
  - SUE가 매번 거의 같은 회사는 SD가 0에 가까워 점수가 폭발한다. 고정값은 산업마다 SUE 수준이 달라 맞지 않아서, 산업 안에서 상대값으로 정한다.
- 극단값: 점수를 ±5로 클립한다. 1·99% 윈저라이즈는 강건성.
  - 점수가 이미 표준화돼 있어 고정 기준이 산업 간 같은 의미("평소보다 5SD 이상")를 가진다. 윈저는 표본에 따라 경계가 달라진다.
- 데이터 오류(GAAP EPS 혼입 등)는 클립과 별개로 EPS 의심 플래그를 출력하고 강건성에서 제외한다.

## 공통 분석 기간 (2026-11-08)

- 분석 이벤트: 발표일 기준 2022-01-01 ~ 2026-09-30 (회사당 약 19개 분기)
- 실적 기록은 발표일 2020-01-01 ~ 2026-10-31을 수집한다(직전 8분기 점수 계산 + 대조군 자기 발표 판정용).
- 주가는 2019-12-01 ~ 2026-10-31을 수집한다(2026-11-12 변경, 기존 2021-07~). 2020~2021 발표의 SUE에도 t0−2 종가가 필요해서다. 끝 날짜는 재실행해도 결과가 같도록 고정한다.
- WRDS 없이 진행한다(2026-11-12). 보험은 Alpha Vantage, 바이오·IT는 yfinance.
- 발표일 기준으로 정하는 이유: 회계연도가 달력과 다른 회사(오라클·어도비·액센츄어 등)도 실제 발표 시기가 맞는다.
- 2022년부터 시작하는 이유: 코로나 시기(2020~2021)의 비정상 실적을 분석에서 뺀다.
- 강건성: 2022년 이벤트의 직전 8분기는 코로나 시기라서, 2023년 이후만 쓴 버전을 추가한다.
  - (2026-11-12 추가) 코로나 시기가 비교 기준에 섞이는 문제를 별도 점검 항목으로 둔다: 2024년 이후 이벤트만(직전 8분기가 모두 2022년 이후), 2020년 발표를 뺀 점수, 코로나 비중 상호작용 등. 세부는 `plans/2026-11-12-did-pipeline-unification.md` 5-3.
  - (2026-11-12 추가) ±10 규칙의 대조군 부족(보험 42%, 바이오 56% 탈락)도 점검 항목으로 둔다. 탈락은 어닝시즌 한가운데 발표로 쏠릴 수 있어 발표 여부 결과의 대표성 문제가 된다. 세부는 같은 문서 5-2.
- 적용: 보험은 2021년 이벤트(약 90건)를 분석에서 빼고 점수 계산·대조군 판정용으로만 쓰며, 2020년 실적을 추가 수집 / 바이오는 2022-01~06 이벤트 추가, 주가 2021-07부터 / IT는 종료일만 2026-09-30으로 맞춤

## 데이터 점검에서 알게 된 것 (2026-11-12)

- yfinance `get_earnings_dates(limit=100)`는 70개사 모두 2020년 이전 기록까지 준다. 분석 기간 발표 시각 불명은 0건이다.
- yfinance EPS는 분할 조정돼 있다. 분할 15건에서 분할 전후 EPS/주가 비율이 분할 비율만큼 뛰지 않았다. 그래서 IT도 SUE(주가 분모)로 바꿔도 분할 문제가 없다.
- 보험의 GAAP EPS 혼입은 Alpha Vantage만의 문제가 아니다. yfinance도 ALL 2025Q2·Q3에 같은 GAAP 값을 준다. 출처를 바꿔서는 해결되지 않으므로 EPS 의심 플래그로 다룬다.
- 바이오 대조군 탈락(파일럿 56%)은 "다른 하위그룹만" 규칙과 2022-06부터 받은 주가 때문이었다. 산업 전체 풀, 2019-12부터 받은 주가로는 98.5%가 대조군을 찾는다. 남는 대조군 부족 문제는 보험(61%)이다.
- 바이오 교란 제외 이벤트: LLY 2025-08-07, VRTX 2025-08-04, LLY 2025-05-01(CVS Caremark 결정), CRL 2025-05-07(Elliott 합의). 경계 이벤트(강건성에서만 제외): WAT 2026-02-09(BD 인수 완료일), VRTX 2025-05-05(VX-522 일부 중단). 판정 기준: 같은 날 실적·가이던스와 별개인 뉴스가 주가를 움직였는가.
- SEC EDGAR 대조(2026-11-12): yfinance 발표일·시각은 8건만 틀렸다(`config/did/t0_overrides.csv`). 보험 GAAP 혼입 25건은 `config/did/eps_overrides.csv`로 보정했다. 바이오·IT에는 GAAP 혼입이 없다. SEC 요청 헤더에는 사용자 이메일을 넣는다(사용자 허락, SEC 요구사항).
- ORI는 8-K가 보도자료보다 하루 늦게 접수되는 경우가 많다. MKL은 실적을 8-K가 아니라 10-Q로 낸다. 두 회사는 8-K 시각으로 반응일을 정하면 안 된다.
