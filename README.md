# 💸 Causal Inference for Financial Event Analysis

KUBIG 26-2 컨퍼런스 프로젝트 — 인과추론 방법론을 금융 시계열 데이터에 적용해 이벤트·정책의 인과적 효과를 추정합니다.

## 개요

금융 데이터 분석에는 정책 변화, 규제 도입, 기업 이벤트가 자산 가격이나 거래량에 미치는 영향을 분석하는 **이벤트 스터디(Event Study)** 의 오랜 전통이 있습니다. 그러나 전통적 이벤트 스터디는 단순 전후 비교나 상관관계 분석에 의존하는 경우가 많아, 동시에 발생하는 다른 요인(시장 전체 흐름, 거시경제 변수 등)과 이벤트 자체의 인과적 효과를 구분하기 어렵다는 한계가 있습니다.

본 프로젝트는 인과추론 방법론을 금융 시계열 데이터에 적용하여, 특정 이벤트나 정책 개입이 **자산 가격·변동성·거래량** 등에 미치는 인과적 효과를 추정하고, 상관관계 기반의 전통적 이벤트 스터디와 인과추론 기반 분석의 차이를 비교·분석합니다.

## 목표

- 인과추론 방법론의 이론적 배경과 가정 이해
- 금융 시계열 데이터에 인과추론 기법을 적용해 특정 이벤트/정책의 효과 추정
- 전통적 상관 기반 이벤트 스터디와 인과추론 기반 분석 결과 비교

## 응용 방향 (후보)

세부 방향은 팀 논의로 선정 예정이며, 후보는 변동될 수 있습니다.

1. **정책/규제 이벤트**가 주가·변동성에 미치는 인과효과
2. **기업 이벤트**(실적발표, M&A, 배당정책 변경)의 인과적 효과 분석
3. **거시경제 충격**(금리 발표 등)이 자산군별로 미치는 이질적 처치효과(Heterogeneous Treatment Effect) 분석

## 진행 방식 및 커리큘럼

인과추론 방법론 리뷰 → 데이터 수집 및 전처리 → 모델 구현 → 실험 분석 순으로 진행합니다. (커리큘럼은 진행 과정에서 변동될 수 있습니다.)

| 주차 | 내용 |
| --- | --- |
| 1주차 | OT |
| 2주차 | 인과추론 방법론 리뷰 |
| 3주차 | 분석할 이벤트/정책 및 데이터셋 선정 |
| 4주차 | 데이터 수집 및 전처리 |
| 5–7주차 | 인과추론 모델 구현 |
| 8주차 | 결과 비교 분석 및 해석 |
| 9주차 | 마무리 및 발표 준비 |
