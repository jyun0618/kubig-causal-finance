# 💸 Causal Inference for Financial Event Analysis

KUBIG 26-2 컨퍼런스 프로젝트 — **기업 실적발표(어닝 서프라이즈)가 주가·거래량에 미치는 순수 인과효과**를 여러 인과추론 방법론으로 추정하고 비교합니다.

## 요약

- **주제**: 기업 실적발표(어닝 서프라이즈)가 주가·거래량에 미치는 순수 인과효과 추정
- **방법**: 전통 이벤트 스터디(CAR), DiD, Synthetic Control, Causal ML을 같은 데이터에 적용해 비교(robustness check)하고, 어떤 회사군에서 효과가 더 큰지(HTE) 분석
- **분석 대상**: 국내·해외 상장사 수십~수백 개 (애플, 네이버, 카카오 포함)

## 배경 및 문제의식

실적발표 날 주가가 올랐다면, 실적발표 **때문에** 오른 건지 그날 시장 전체가 좋아서 오른 건지 구분하기 어렵습니다. 회사에서는 보통 A/B 테스트로 이런 문제를 풀지만, 금융 이벤트에서는 무작위 실험이 불가능합니다.

이 프로젝트는 인과추론 기법으로 "시장 전체가 오른 부분"을 걷어내고 "오직 실적발표 때문에 생긴 부분"만 추정합니다.

## 목표

1. 실적발표 서프라이즈가 주가·거래량에 미치는 순수효과를 여러 방법론으로 각각 추정
2. 방법론별 결과가 서로 다른지, 다르다면 **왜** 다른지 분석
3. 어떤 회사 특성(대형주/소형주, 산업군 등)에서 효과가 더 크게 나타나는지 분석

## 방법론

| 방법론 | 핵심 아이디어 | 전제·한계 |
| --- | --- | --- |
| **① 이벤트 스터디 (CAR)** | 시장 모형으로 "평소대로 움직였을 때"의 기대수익률을 예측하고, 실제 수익률과의 차이(초과수익)를 누적 | "평소 패턴"을 시장 지수 하나로 단순화해 산업 이슈 등 다른 요인을 놓칠 수 있음 |
| **② DiD (이중차분법)** | 실적발표 기업(처치군)과 발표하지 않은 유사 기업(대조군)의 발표 전후 변화량 차이를 비교 | 평행추세 가정 필요 |
| **③ Synthetic Control (합성 통제법)** | 여러 기업을 가중 조합해 발표 전 움직임이 가장 비슷한 "합성 쌍둥이 기업"을 만들어 비교 | 적절한 대조군 하나를 고르기 애매할 때 유용 |
| **④ HTE / Causal ML** | 평균효과가 아니라 집단별(규모·산업·애널리스트 커버리지 등) 이질적 처치효과를 추정 | Meta-learner(S/T/X), Causal Forest, Double ML 등 활용 |

**HTE 분석 질문 예시**

- 대형주와 소형주에서 효과가 다른가?
- 테크 기업과 전통 산업에서 효과가 다른가?
- 애널리스트 커버리지가 많은 회사와 적은 회사에서 효과가 다른가?

## 데이터

- **국내**: 네이버, 카카오 등 코스피·코스닥 상장사의 주가·거래량 및 분기 실적발표 데이터
- **해외**: 미국 상장사 (yfinance, WRDS 등)
- **실적 컨센서스**: 애널리스트 예상치 — 어닝 서프라이즈를 계산하는 기준값

## 일정

| 주차 | 할 일 |
| --- | --- |
| 1주차 | OT |
| 2–3주차 | CAR / DiD / Synthetic Control 이론 공부 |
| 4주차 | 분석 대상 기업 리스트, 실적발표일·컨센서스 데이터 확정 |
| 5주차 | 주가·거래량 데이터 수집 및 전처리 |
| 6주차 | ① CAR 구현 |
| 7주차 | ② DiD 구현 (+ 평행추세 검증) |
| 8주차 | ③ Synthetic Control 구현, ④ HTE 분석 |
| 9주차 | 방법론별 결과 비교, robustness check, 발표 준비 |

### 확장 과제 (시간이 허락하면)

- **Spillover / SUTVA 위반**: 반도체 A사의 실적이 좋으면 같은 업종 B사 주가도 함께 오를 수 있습니다. B사를 대조군으로 쓰면 대조군이 오염되어 DiD 추정이 틀어지므로, 이 전파 효과를 다루는 실험을 추가합니다.
- 더 정밀한 HTE 분석
